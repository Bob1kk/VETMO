# VETMO — помощник в драфте Dota 2

VETMO — настольное приложение для Windows, которое помогает выбирать героев
в Dota 2 в режиме All Pick. Поверх игры открывается прозрачный оверлей с двумя
досками пиков (Radiant и Dire, по пять позиций), а под ними — подсказки
по актуальной мете: винрейты, пикрейты, банрейты и контрпики.

Приложение рассчитано на игроков, которые хотят видеть статистику и варианты
пика во время драфта, не переключаясь в браузер. Интерфейс на русском языке,
установка не требует прав администратора и установленного Python.

## Возможности

- **Лаунчер.** Новости Dota 2 из Steam RSS, таблица меты по патчам, рангам
  и позициям, настройки оверлея, выбор темы и кнопка включения оверлея.
  Окно открывается менее чем за три секунды.
- **Оверлей поверх игры.** Окно без рамки, всегда сверху, с настраиваемой
  прозрачностью и режимом click-through. Позиция и прозрачность сохраняются
  между запусками; оверлей перетаскивается мышью за шапку.
- **Доска пиков.** У каждой команды пять кликабельных клеток — позиции 1–5.
  Клик по пустой клетке открывает выбор героя с фильтром по атрибутам
  (сила, ловкость, интеллект, универсал) и поиском. Клик по заполненной
  клетке заменяет героя, крестик убирает пик.
- **Подсказки.** После каждого пика обновляется блок рекомендаций для обеих
  команд: кандидаты ранжируются по мете, винрейту и контрпикам с учётом уже
  выбранных героев и позиции.
- **Офлайн-режим.** Каталог героев и последняя загруженная мета доступны без
  сети; настройки и драфты хранятся локально.

## Установка и первый запуск

1. Откройте страницу релизов
   <https://github.com/Bob1kk/VETMO/releases> и скачайте
   `VETMO-Setup-<версия>.exe` из последнего релиза (раздел **Assets**).
2. Запустите установщик. Он ставит приложение в профиль пользователя
   (`%LOCALAPPDATA%\Programs\VETMO`), права администратора не нужны.
3. Запустите VETMO: Python и библиотеки уже включены в установщик. При первом
   запуске нужен интернет для меты и новостей; каталог героев доступен офлайн.
4. Переключите Dota 2 в режим **borderless/windowed** и нажмите «Оверлей»
   в лаунчере.

Установщики не подписаны код-сертификатом, поэтому Windows SmartScreen может
показать предупреждение. Подробная инструкция — в
[`docs/user-setup-guide.md`](docs/user-setup-guide.md).

## Как это работает

Приложение написано на Python с графическим интерфейсом на PySide6 (Qt 6).
Код разделён на слои, зависимости направлены внутрь:

```
ui → viewmodels → services → domain
                     ↓
                    data / infra
```

`ui` содержит окна, виджеты, модели представления и фоновые задачи — без SQL
и прямых HTTP-запросов. `services` реализует сценарии: мету, рекомендации,
драфт, настройки, синхронизацию и CV. `domain` — чистые модели и правила,
`data` — ORM, репозитории, Alembic и SQLite, `infra` — конфигурацию, HTTP,
прокси и Supabase.

Оверлей — отдельное окно Qt без рамки и без захвата фокуса. Обычно оно
принимает клики; в режиме click-through щелчки проходят сквозь него в игру.
Обе доски и подсказки обновляются из одного состояния драфта, поэтому замена
героя сразу пересчитывает рекомендации.

Порядок ходов задан в `src/vetmo/domain/rules.py`: Radiant — Radiant — Dire —
Dire — Radiant — Dire — Dire — Radiant — Radiant — Dire; всего десять пиков,
по пять на команду. Позиция героя (1–5) хранится вместе с пиком.

## База данных

### Supabase

Основной источник справочных данных — проект Supabase. Схема лежит в
`supabase/migrations`, стартовые данные героев — в `supabase/seed`.
Справочные таблицы: `vetmo_heroes`, `vetmo_patches`, `vetmo_meta`,
`vetmo_snapshots`, `vetmo_hero_matchups`, `vetmo_ban_stats`, `vetmo_news`.
Пользовательские данные — `vetmo_profiles`, `vetmo_drafts`,
`vetmo_draft_picks`; журнал синхронизации — `vetmo_sync_runs`.

Представления `v_vetmo_meta`, `v_vetmo_matchup_highlights` и
`v_vetmo_sync_status` дают человекочитаемые срезы для приложения и панели
Supabase. Для всех таблиц включён Row Level Security: ключ `anon` /
`publishable` читает только справочные таблицы, запись в них запрещена.
Пользовательские настройки и драфты привязаны к анонимной сессии и доступны
только её владельцу. Ключ `service_role` обходит RLS и используется только
инструментом сопровождения и скриптами синхронизации.

### SQLite и офлайн-режим

Локальная SQLite-база (`vetmo.db`) и миграции Alembic
(`src/vetmo/data/migrations`) остаются резервным хранилищем и используются
при разработке и в офлайн-режиме. Настройки оверлея и драфты дополнительно
сохраняются в `%APPDATA%\VETMO\settings.json` и `drafts.json`: если Supabase
недоступен, приложение продолжает работать на локальных данных.

Миграции Supabase применяются через SQL Editor или скрипт
`scripts/apply_migration.ps1`; проверка набора таблиц и представлений —
`scripts/check_supabase_schema.py`. Порядок настройки описан в
[`docs/supabase-setup.md`](docs/supabase-setup.md).

## Данные и синхронизация

- **OpenDota** — каталог героев, `heroStats` (винрейт, пикрейт, банрейт),
  `matchups` (контрпики), патчи и иконки. Клиент соблюдает лимит
  **60 запросов в минуту**, повторяет неудачные запросы и кэширует ответы
  не менее чем на **24 часа**.
- **STRATZ GraphQL** — агрегированная мета по рангам и позициям, бан-статистика
  и матчапы. Данные приводятся к схеме `vetmo_meta`; окно расчёта — семь дней,
  минимальная выборка для показа — 50 матчей.
- **Валидатор** проверяет имена героев, диапазоны значений (винрейт 0–100)
  и URL иконок, а некорректные записи отправляет в карантин — в интерфейс
  они не попадают.
- **Кэш** снижает нагрузку на API: новости обновляются раз в час, иконки
  хранятся локально в `assets/cache`.
- **Сеть.** Приложение учитывает системный прокси Windows и переменные
  `HTTP_PROXY` / `HTTPS_PROXY` — это полезно при работе через локальный туннель.

Синхронизация выполняется скриптами из папки `tools/`. Им нужен файл
`%APPDATA%\VETMO\secrets.env` с ключом `service_role` и токеном STRATZ.
Пользовательскому приложению эти секреты не нужны.

## Скрипты

| Команда | Что делает |
|---|---|
| `tools\sync_opendota.py` | загружает героев, патчи и мету из OpenDota в Supabase |
| `tools\sync_stratz.py` | загружает агрегаты, бан-статистику и матчапы из STRATZ |
| `scripts\build_release.ps1` | тесты, обе сборки, проверки состава, установщики, smoke-запуски |
| `scripts\publish_release.ps1` | создаёт или обновляет GitHub Release и прикрепляет установщики |
| `scripts\apply_migration.ps1` | применяет SQL-миграции к проекту Supabase |
| `scripts\check_supabase_schema.py` | проверяет наличие таблиц и представлений |
| `pytest`, `ruff check`, `mypy` | тесты, линтер и проверка типов |

Проверки запускаются из корня проекта:
`.\.venv\Scripts\python.exe -m pytest`, `... -m ruff check src tests`,
`... -m mypy src/vetmo`.

| Установщик | Для кого | Каталог |
|---|---|---|
| `VETMO-Setup-<версия>.exe` | игрок | `%LOCALAPPDATA%\Programs\VETMO` |
| `VETMO-Admin-Setup-<версия>.exe` | управляющие | `%LOCALAPPDATA%\Programs\VETMO Admin` |

Оба установщика работают без прав администратора и поддерживают тихую
установку (`/VERYSILENT`). `scripts/publish_release.ps1` берёт версию из
`src/vetmo/__init__.py`, создаёт тег `v<версия>` и прикрепляет файлы
к GitHub Release; готовые установщики также лежат в `release/` ветки
`release/public-installer`. Портативная сборка `dist/VETMO.exe` запускается
без установки, но предназначена для проверки и разработки.


## VETMO Admin

`VETMO-Admin.exe` — отдельное приложение для наполнения меты: просмотр
справочных данных, запуск синхронизации OpenDota и STRATZ, история запусков
и диагностика подключений. Оно не входит в пользовательский установщик.
Перед запуском создайте `%APPDATA%\VETMO\secrets.env` по образцу
`installer/ADMIN-SETUP.txt`. Проверить конфигурацию без графического интерфейса
можно командой `VETMO-Admin.exe --self-check`.

## Структура проекта

```
src/vetmo/
├── domain/        # модели, правила драфта, рекомендации
├── data/          # ORM, репозитории, SQLite, миграции Alembic
├── services/      # мета, новости, драфт, настройки, синхронизация, CV
├── ui/            # PySide6: окна, виджеты, модели представления, темы
├── infra/         # конфигурация, логирование, HTTP, прокси, Supabase
├── admin/         # приложение сопровождения
└── main.py        # точка входа пользовательского приложения
tests/             # unit, интеграционные и admin-тесты
tools/             # скрипты синхронизации
scripts/           # сборка, публикация, миграции, проверка схемы
supabase/          # SQL-миграции и seed-данные
installer/         # сценарии Inno Setup
assets/            # кэш иконок героев
```

## Известные ограничения

- **Нет код-подписи.** Установщики и exe не подписаны, поэтому SmartScreen
  может показать предупреждение. Для публичного релиза нужна подпись
  Authenticode.
- **Синергии.** OpenDota не отдаёт готовые данные синергий, поэтому подсказки
  опираются на мету и контрпики; таблица синергий оставлена для будущих
  источников.
- **Сеть и прокси.** Без интернета доступны только локальный каталог героев,
  сохранённые настройки и драфты; свежая мета и новости не загружаются.
  При нестандартном прокси может потребоваться переменная `HTTPS_PROXY`.
- **Один профиль на компьютер.** Настройки и драфты привязаны к анонимной
  сессии Supabase и локальной папке `%APPDATA%\VETMO`.
