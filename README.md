# VETMO — помощник в драфте Dota 2

VETMO — десктопный помощник при выборе героев в режиме All Pick (Dota 2). В окне
пика вы открываете прозрачный оверлей поверх игры: у каждой команды (Radiant
слева, Dire справа) есть доска из 5 клеток по позициям 1–5. Клик по пустой
клетке открывает выбор героя с фильтром по атрибутам (сила/ловкость/интеллект/
универсал) и поиском; выбранные герои сразу учитываются в блоке подсказок
«снизу» — там появляются лучшие кандидаты для обеих команд по актуальной мете
(винрейты, пикрейты, контрпики и синергии). Оверлей полупрозрачный и
перетаскивается мышью за шапку. Драфт идёт по правилу 2-2-1 (10 пиков),
приложение подсказывает, кто пикует сейчас. Данные берутся из меты проекта,
локальный каталог героев доступен офлайн; пики можно распознавать автоматически
по иконкам (экспериментальное CV) или вводить вручную.

## Возможности

- **Лаунчер (FR-001).** Окно с новостями Dota 2, таблицей меты, настройками
  оверлея, выбором темы (тёмная/светлая) и кнопкой включения оверлея. Окно
  появляется менее чем за 3 секунды.
- **Настройки оверлея (FR-002).** Позиция, прозрачность, always-on-top,
  click-through. Всё сохраняется и восстанавливается при следующем запуске;
  оверлей можно перетаскивать мышью за шапку — новая позиция сохраняется
  автоматически.
- **Показ/скрытие оверлея (FR-003).** Кнопка в лаунчере переключает оверлей,
  не закрывая его и не перезапуская приложение.
- **Доска пиков в оверлее (FR-004).** У каждой команды 5 кликабельных клеток
  (позиции 1–5): клик открывает выбор героя с фильтром по атрибутам и поиском,
  крестик убирает пик. Под клетками — блок подсказок «снизу»: лучшие кандидаты
  для Radiant и Dire с учётом уже выбранных героев, винрейта и контрпиков.
- **Рекомендации (FR-004).** Подсказки обновляются после каждого выбранного или
  убранного героя; учитываются мета, винрейт и контрпики.
- **Машина состояний драфта (FR-005).** Последовательность пиков 2-2-1,
  индикатор текущего шага, максимум 10 пиков.
- **Синхронизация с OpenDota (FR-006).** Герои, винрейты, пик-рейты, контрпики,
  синергии; после синхронизации в базе 120+ героев.
- **Валидатор данных (FR-007).** Имена героев, диапазоны значений, URL иконок;
  невалидные записи попадают в карантин и не показываются.
- **Ручной ввод пиков (FR-008).** Диалог ручного ввода как запасной вариант,
  обновляет драфт и пересчитывает рекомендации.
- **CV-распознавание пиков (FR-009, экспериментально).** Захват экрана + шаблонное
  совпадение иконок героев; найденные пики можно подтвердить или исправить.

## Известные ограничения беты

- **Синергии:** таблица и репозиторий готовы, но OpenDota не отдаёт данные синергий —
  скоринг опирается на мету (pub win/pick) и контр-пики (`/heroes/{id}/matchups`).
- **Неподписанный установщик:** публичные сборки не подписаны код-сертификатом,
  поэтому Windows SmartScreen может показать предупреждение. Для релиза
  рекомендуется Authenticode-подпись setup и `VETMO.exe`.
- **CV-распознавание** — эксперимент: пики всегда можно внести/исправить вручную
  через «Ручной ввод пика…».
- Сетевой доступ учитывает системный прокси Windows; кэш ≥ 24 ч даёт офлайн-режим.

## Быстрый старт (игрок)

1. Откройте страницу релизов — <https://github.com/Bob1kk/VETMO/releases> —
   и скачайте `VETMO-Setup-<версия>.exe` из последнего релиза (раздел
   **Assets**).
   Резервная копия установщиков — папка `release/` ветки
   `release/public-installer`.
   Установка идёт в профиль пользователя (`%LOCALAPPDATA%\Programs\VETMO`),
   права администратора не нужны. Ярлык появляется в меню «Пуск».
2. Запустите VETMO. Python и дополнительные библиотеки не требуются — всё
   включено в установщик.
3. При первом запуске приложение подключается к Supabase за мета-данными и
   новостями (нужен интернет; каталог героев есть в exe и доступен офлайн).
4. В окне пика Dota 2 нажмите кнопку «Оверлей» в лаунчере.

Как пользоваться доской оверлея:

- **Перетаскивание.** Возьмите оверлей за шапку (там же бренд, счётчик шага и
  шестерёнка) и переставьте куда удобно — позиция сохранится.
- **Выбор героя.** Кликните по пустой клетке нужной команды и позиции, выберите
  героя в диалоге (фильтр «Сила / Ловкость / Интеллект / Универсал» + поиск)
  и нажмите «Выбрать».
- **Подсказки.** Под клетками каждой команды сразу обновляется блок «ПОДСКАЗКИ»
  с лучшими вариантами по мете и контрпикам.
- **Исправление.** Клик по заполненной клетке заменяет героя, крестик «×» —
  убирает пик.
- В режиме click-through клетки не кликаются: снимите галочку click-through в
  настройках лаунчера, чтобы вернуть управление оверлеем.

Настройки и драфты сохраняются в `%APPDATA%\VETMO`, логи — в
`%APPDATA%\VETMO\logs`. Секретные файлы для пользовательской версии не нужны.

Портативный вариант: `dist\VETMO.exe` можно запускать без установки — это
single-file сборка (~64 МБ).

**Требования:** Windows 10/11 (64-бит). Интернет нужен для меты, новостей и
синхронизации настроек; без сети остаются локальный каталог героев, настройки
и драфты.

## Сборка из исходников

```powershell
py -3.12 -m pip install uv
py -3.12 -m uv sync                 # создать .venv и установить зависимости
.\.venv\Scripts\python.exe -m PyInstaller vetmo.spec
```

Результат: `dist/VETMO.exe` (one-file, без консоли). Спека `vetmo.spec`
исключает тяжёлые библиотеки, которых нет в зависимостях (matplotlib, tkinter,
PyQt5/6, tornado, jupyter и т.п.), а также admin/sync-код с service_role.

## Публикация релиза

Для сборки установщиков нужен [Inno Setup 6.7+](https://jrsoftware.org/isinfo.php)
(компилятор `ISCC.exe`). Полная проверка релиза одной командой:

```powershell
.\scripts\build_release.ps1
```

Скрипт собирает **обе** версии и **оба** установщика:

1. запускает pytest, ruff и mypy;
2. собирает `dist/VETMO.exe` и `dist/VETMO-Admin.exe`;
3. проверяет пользовательскую сборку: нет admin/sync-модулей и значений
   секретов из `%APPDATA%\VETMO\secrets.env`, присутствует публичная
   конфигурация Supabase;
4. проверяет админскую сборку: модули `vetmo.admin` и `vetmo.services.stratz_sync`
   на месте, значений секретов внутри нет;
5. запускает обе сборки с чистым `APPDATA` (без `.env`/`secrets.env`) и
   проверяет, что процессы живы и создан лог;
6. собирает `release/VETMO-Setup-<версия>.exe` (игрок) и
   `release/VETMO-Admin-Setup-<версия>.exe` (админ);
7. тихо устанавливает и удаляет каждый установщик, проверяя установленный exe.

Если Inno Setup установлен в нестандартное место:

```powershell
.\scripts\build_release.ps1 -IsccPath "C:\Tools\Inno Setup 6\ISCC.exe"
```

Для сборки exe без установщиков: `-SkipInstaller`; без тестов — `-SkipTests`;
без smoke-запусков — `-SkipSmoke`. Перед сборкой закройте запущенные
VETMO/VETMO-Admin. Установщики и exe не подписаны — для публичного релиза
добавьте Authenticode-подпись.

### Публикация в GitHub Releases

После успешной сборки опубликуйте артефакты в Releases — именно оттуда
игроки скачивают установщик:

```powershell
.\scripts\publish_release.ps1
```

Скрипт берёт версию из `src/vetmo/__init__.py`, создаёт тег/релиз `v<версия>`
на ветке `release/public-installer` и прикрепляет
`VETMO-Setup-<версия>.exe` и `VETMO-Admin-Setup-<версия>.exe`.
Если релиз уже есть, он обновляется, а файлы заменяются
(`-KeepExistingAssets` — не перезаливать уже прикреплённые).

Токен нужен со scope `repo`: скрипт читает `$env:GH_TOKEN` / `$env:GITHUB_TOKEN`,
а если их нет — берёт сохранённый токен из Git Credential Manager
(`git credential fill`). Полезные флаги: `-Tag v0.2.0`, `-Draft`,
`-Prerelease`, `-NotesFile notes.md`, `-Name "VETMO 0.2.0"`.

### Установщики

| Файл | Для кого | Каталог установки | Особенности |
|---|---|---|---|
| `installer/VETMO.iss` → `release/VETMO-Setup-<версия>.exe` | Игрок | `%LOCALAPPDATA%\Programs\VETMO` | per-user, без прав администратора, ярлык в «Пуск» |
| `installer/VETMO-Admin.iss` → `release/VETMO-Admin-Setup-<версия>.exe` | Сопровождение | `%LOCALAPPDATA%\Programs\VETMO Admin` | создаёт пустой `%APPDATA%\VETMO`, кладёт `ADMIN-SETUP.txt`; секреты не копирует |

Оба установщика работают без прав администратора и поддерживают тихую установку
(`/VERYSILENT`) — это используется в автотесте сборочного скрипта.

### Где лежат готовые сборки

Основной канал для игроков — страница релизов
<https://github.com/Bob1kk/VETMO/releases>: в последнем релизе в разделе
**Assets** прикреплены `VETMO-Setup-<версия>.exe` и
`VETMO-Admin-Setup-<версия>.exe`.

Те же файлы дополнительно закоммичены в ветку `release/public-installer`
в папку `release/` (исключение в `.gitignore`), чтобы их можно было скачать
и без релиза; остальные артефакты (`dist/`, `build/`) не коммитятся.

После пересборки: закоммитьте установщики
и создайте (или обновите) GitHub Release с теми же файлами, чтобы скачанный
пользователем установщик соответствовал ветке.

## VETMO Admin (инструмент сопровождения)

`VETMO-Admin.exe` — отдельное приложение для тех, кто наполняет мету:
просмотр reference-данных, запуск sync (OpenDota + STRATZ) и история запусков.
Ему нужны секреты (пользовательской версии — нет). Установите
`VETMO-Admin-Setup-<версия>.exe`, затем создайте `%APPDATA%\VETMO\secrets.env`
по образцу `installer/ADMIN-SETUP.txt` и запустите Admin.

## Разработка

```powershell
py -m uv sync                      # uv (рекомендуется) или pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest          # unit + интеграционные тесты
.\.venv\Scripts\python.exe -m ruff check src tests
.\.venv\Scripts\python.exe -m mypy src/vetmo --ignore-missing-imports
.\.venv\Scripts\python.exe src/vetmo/main.py  # запуск из исходников
```

Конфигурация линтера и типизации — в `pyproject.toml` (ruff: E/F/W/I/UP/B,
mypy: `check_untyped_defs`, `ignore_missing_imports`).

## Структура проекта

```
src/vetmo/
├── domain/        # чистые модели и правила драфта (pydantic, без I/O)
├── data/          # SQLAlchemy ORM, репозитории, Alembic-миграции, SQLite
├── services/      # бизнес-логика: OpenDota-клиент, синк, оверлей, CV, настройки
├── ui/            # PySide6: окна, виджеты, viewmodels, воркеры, тема (QSS)
├── infra/         # конфиг (.env), логирование, httpx, системный прокси
└── main.py        # точка входа: QApplication + MainWindow
tests/             # pytest (+ pytest-qt): unit и интеграционные тесты
assets/            # кэш иконок героев (наполняется в рантайме)
```

Слои разделены: SQL и HTTP живут только в `data/` и `services/`,
в `ui/` — никаких запросов к БД/сети (viewmodels вызывают сервисы).

## Dota 2: что важно знать

- Окно Dota 2 лучше переключить в **borderless/windowed** — оверлей поверх
  полноэкранного режима не гарантируется.
- Оверлей всегда поверх окна игры (always-on-top), у окна нет рамки и фокуса.
- В режиме click-through оверлей **не кликается**: все щелчки проходят сквозь
  него в игру и интерфейс Dota 2 (клики сквозь него). Чтобы вернуть клик по
  оверлею, снимите галочку в настройках лаунчера.
- Ручной ввод пиков — запасной способ, если CV-распознавание ошибается.

## Сеть и лимиты OpenDota

- Соблюдается rate limit OpenDota: не более 60 запросов в минуту, кэш меты ≥ 24 ч;
  офлайн приложение работает на локальной базе.
- Приложение подхватывает **системный прокси Windows** (реестр, как у .NET) и
  переменные `HTTP_PROXY`/`HTTPS_PROXY` — полезно при локальных туннелях
  (v2rayN/Clash), где прямой доступ к OpenDota блокируется.

## Секреты

Пользовательской версии не нужны секретные файлы. В exe вшиты публичные
параметры Supabase: URL проекта и `publishable`/`anon`-ключ. Это не секрет —
ключ предназначен для клиентских приложений, а доступ ограничен RLS; он
задан в `src/vetmo/infra/public_config.py`. Все настройки можно переопределить
через `.env` (шаблон — `.env.example`, переменные с префиксом `VETMO_`).

Секреты нужны только VETMO Admin и sync-скрипту: `service_role` и STRATZ-токен
читаются из `%APPDATA%\VETMO\secrets.env`, не коммитятся и не попадают в
пользовательский `VETMO.exe`. Сборочный скрипт проверяет это побайтово и по
значениям из локального `secrets.env`.
