# n8n webhook (заглушка, не реализуется в этой итерации)

В будущих версиях VETMO будет поддерживать вебхук n8n для уведомлений,
например: «синхронизация меты завершена», «обнаружен новый патч», «драфт завершён».

## Планируемый контракт

- Точка вызова: `infra` → `hooks.n8n_hook.send(event: str, payload: dict) -> bool`
- Триггеры: `meta_sync_completed`, `patch_detected`, `draft_finished`
- Транспорт: HTTP POST на URL из `.env` (`N8N_WEBHOOK_URL`, не реализовано)
- Доставка уведомления: fire-and-forget с ретраем 1 раз; ошибки только в логах,
  никогда не блокируют UI.

## Статус

Не реализовано (out of scope, см. раздел 3 плана: «n8n не реализуется в этой итерации»).
