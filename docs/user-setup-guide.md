# Установка и первый запуск VETMO

## Требования

- Windows 10 или Windows 11, 64-бит.
- Интернет для загрузки меты и новостей. Каталог героев доступен офлайн.
- Права администратора не нужны.

## Установка

1. Откройте страницу релизов:
   <https://github.com/Bob1kk/VETMO/releases>.
2. В последнем релизе скачайте `VETMO-Setup-<версия>.exe` из раздела **Assets**.
3. Запустите установщик. Приложение ставится в профиль пользователя:
   `%LOCALAPPDATA%\Programs\VETMO`.
4. Ярлык VETMO появится в меню «Пуск».

Установщик не подписан код-сертификатом. Windows SmartScreen может показать
предупреждение: нажмите «Подробнее» → «Выполнить всё равно».

## Первый запуск

1. Запустите VETMO из меню «Пуск».
2. При первом запуске приложение загрузит мету и новости. Нужен интернет.
3. Переключите Dota 2 в режим **borderless/windowed**: оверлей поверх
   полноэкранного режима не гарантируется.
4. В лаунчере нажмите **«Запустить оверлей»**.

## Оверлей

- Оверлей открывается поверх игры, не забирает фокус и перетаскивается
  за шапку.
- В настройках можно изменить непрозрачность, тему, положение и включить
  режим click-through.
- В режиме click-through клики проходят сквозь оверлей в игру. Чтобы
  вернуть управление оверлеем, снимите галочку в настройках лаунчера.
- Пики можно отмечать вручную или распознавать по экрану. Если
  распознавание ошиблось, пик всегда можно исправить вручную.

## Настройки и данные

- Настройки: `%APPDATA%\VETMO\settings.json`.
- Драфты: `%APPDATA%\VETMO\drafts.json`.
- Логи: `%APPDATA%\VETMO\logs`.
- Локальная база: `vetmo.db` в папке приложения.

Секретные файлы пользовательской версии не нужны.

## Обновление

Скачайте новый установщик со страницы релизов и запустите его. Настройки
и драфты сохраняются в `%APPDATA%\VETMO` и не удаляются.

## Удаление

Параметры Windows → Приложения → VETMO → Удалить. Настройки и драфты
останутся в `%APPDATA%\VETMO`; их можно удалить вручную, если они больше
не нужны.

## Портативная версия

`VETMO.exe` из `dist/` можно запускать без установки. Портативная сборка
предназначена для проверки и разработки; для обычной игры удобнее
установщик.

## Если что-то не работает

- **SmartScreen блокирует запуск.** Нажмите «Подробнее» → «Выполнить всё равно».
- **Оверлей не кликается.** Снимите режим click-through в настройках.
- **Оверлей не виден в игре.** Переключите Dota 2 в borderless/windowed.
- **Нет меты или новостей.** Проверьте интернет и системный прокси.
- **Ошибка распознавания пиков.** Внесите пики вручную через доску оверлея.

Если проблема повторяется, приложите файл из `%APPDATA%\VETMO\logs`
к описанию ошибки.
